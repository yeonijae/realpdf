# realpdf

Windows용 무료 PDF 편집 프로그램입니다. 개발자: **Realhani.com**.

[Windows x64 다운로드](https://github.com/yeonijae/realpdf/releases/latest)

현재 배포는 개발 미리보기입니다. 종이 출력 검증이 남아 있으며 전체 기능명세 완료판은 아닙니다. 버전별 변경 내용과 확인 범위는 Releases 설명을 참고하세요.

## 실행

Releases에서 realpdf-버전-windows-x64.zip을 내려받아 압축을 풀고 realpdf.exe를 실행하세요. engine과 licenses를 포함한 폴더 전체를 유지해야 합니다. Windows의 .NET Framework 4.8과 Microsoft Visual C++ x64 런타임이 필요합니다. WSL은 필요하지 않습니다. HTML 원본 레이아웃 변환에는 설치된 Microsoft Edge를 사용합니다.

SHA256SUMS.txt로 다운로드 파일의 SHA-256을 확인할 수 있습니다. 새 버전을 교체하기 전에 작업 문서를 저장하고 프로그램을 종료하세요.

## 배포·이용

realpdf는 무료로 사용할 수 있습니다. 자체 애플리케이션 소스 코드는 공개하지 않습니다. 이 저장소에는 안내 문서만 제공하며 실행 파일은 Releases에서 배포합니다. GitHub가 자동으로 제공하는 Source code 압축에는 이 안내 문서만 포함됩니다.

[무료 사용 안내](REALPDF-LICENSE.txt)를 참고하세요. 배포 ZIP의 THIRD_PARTY_NOTICES.txt 및 licenses/에 포함된 제3자 라이선스는 각각 그대로 적용됩니다.
